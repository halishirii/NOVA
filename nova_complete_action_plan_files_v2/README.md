# نسخه کامل دستیار اکشن‌پلن و مدیریت پزشکان

این بسته شامل تمام قابلیت‌هاست:
1. آپلود فایل پزشکان (CSV / TSV / TXT / JSON) + فایل نمونه CSV + ثبت و حذف پزشک
2. تولید اکشن‌پلن ویزیت بر اساس تاریخ شمسی، تعداد ویزیت روزانه، حداقل فاصله تکرار و حذف جمعه + خروجی CSV
3. آرایه اتصالات (تست لوکال، API لوکال، سرور عمومی VPS، سرور با VPN)
4. ورود/خروج کاربر، قفل دیتابیس (HOSSEIN1994@) و ثبت لاگ تمام فعالیت‌ها
