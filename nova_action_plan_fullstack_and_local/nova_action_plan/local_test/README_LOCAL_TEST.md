# راهنمای اجرای لوکال و تست (Local & Server Package)

## ۱. تست سریع بدون نیاز به سرور
فایل `frontend/index.html` را در مرورگر باز کنید و پروفایل را روی **حالت ۱: تست لوکال (بدون نیاز به سرور)** بگذارید.
ورود آزمایشی: نام کاربری `hossein` و رمز `HOSSEIN1994@`.

## ۲. اجرای واقعی بک‌اند + دیتابیس روی سیستم لوکال
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
سپس در `frontend/index.html` پروفایل را روی **حالت ۲: لوکال به API لوکال (`http://127.0.0.1:8000`)** قرار دهید تا تمام ورودها، خروج‌ها، ثبت/ویرایش‌ها و لاگ‌ها روی دیتابیس لوکال ذخیره شوند.

## ۳. انتقال به سرور VPS عمومی برای ۵۰ کاربر
1. فایل‌های `backend/` را به VPS منتقل کرده و سرویس `uvicorn` را پشت `Nginx` (با `systemd`) بالا بیاورید.
2. در `frontend/index.html` آدرس پروفایل `vps_public` را به `http://IP_سرور:8000` یا دامنه خود تغییر دهید.
