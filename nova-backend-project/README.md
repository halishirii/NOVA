# پروژه بکند و فرانت‌اند امن نووآ (NOVA)

در این ساختار، احراز هویت و دسترسی به دیتابیس Firebase Firestore به یک سرویس بکند مجزا (`backend/`) منتقل شده است تا:
- هیچ نام کاربری یا رمز عبوری در کد فرانت‌اند (`frontend/index.html`) قرار نگیرد.
- رمز عبور کاربران در Firestore به صورت **هش‌شده (`bcrypt`)** ذخیره شود (و هیچ‌گاه به کلاینت برگردانده نشود).
- دسترسی به داده‌های ویزیت و مشتریان فقط با **توکن JWT** معتبر و از طریق بکند انجام شود.

## اجرای بکند
1. وارد پوشه `backend` شوید:
   ```bash
   cd backend
   npm install
   ```
2. فایل `.env.example` را به `.env` تغییر نام دهید و مقادیر `JWT_SECRET` و مسیر کلید سرویس‌اکانت فایربیس (`serviceAccountKey.json`) را تنظیم کنید.
3. سرور را اجرا کنید:
   ```bash
   npm run dev
   ```
