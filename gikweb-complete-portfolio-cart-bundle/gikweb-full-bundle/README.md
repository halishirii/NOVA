# گیک‌وب (GIKWEB) — بسته یکپارچه فرانت‌اند، نمونه‌کارها و بک‌اند

این فایل زیپ شامل موارد زیر است:
- `frontend/index.html`: رابط کاربری کامل گیک‌وب با تم پاستلی روشن و تم تیره، ۸ نمونه‌کار قابل ورود در فضای ایزوله، ۳ پالت رنگی متفاوت برای هر پروژه، قابلیت‌های اختصاصی قیمت‌دار برای هر پروژه، فرم توضیحات اختصاصی کاربر و سبد خرید یکپارچه متصل به ورود شماره موبایل + کپچا + OTP.
- `backend/`: پروژه NestJS + TypeScript با رمزنگاری `AES-256-GCM`، گارد ضدربات، کپچای سمت سرور در Redis، احراز هویت OTP، و معماری چنددرگاهی پرداخت بانکی.
