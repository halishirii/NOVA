# پکیج کامل تست و پیاده‌سازی گیک‌وب (نسخه ۲)

این بسته به‌گونه‌ای طراحی شده که بتوانید کل سامانه **گیک‌وب** را هم به‌صورت **تست محلی سریع (بدون نیاز به نصب Redis یا سرور بیرونی در اولین تست)** و هم در **محیط کامل با Redis و درگاه‌های بانکی** اجرا و تست کنید.

## محتوای بسته
- `frontend/index.html`: رابط کاربری کامل گیک‌وب با قابلیت اتصال خودکار به بک‌اند در صورت روشن بودن API (`http://localhost:4000`) و حالت Fallback هوشمند برای تست آفلاین/لوکال.
- `backend/`: سرور NestJS + TypeScript با کپچا، OTP، رمزنگاری AES-256-GCM، گارد ضدربات و پرداخت چنددرگاهی.
- `scripts/test-api.sh`: اسکریپت تست خودکار مسیرهای `/captcha/challenge`، `/auth/request-otp`، `/auth/verify-otp` و `/orders`.

## مراحل تست سریع روی سیستم
1. باز کردن فایل `frontend/index.html` در مرورگر (یا سرو کردن آن با یک وب‌سرور ساده مثل `npx serve frontend`).
2. تست ورود به هر یک از ۸ نمونه‌کار، تغییر پالت رنگی، انتخاب قابلیت‌های قیمت‌دار، نوشتن توضیحات و افزودن به سبد خرید.
3. برای تست بک‌اند:
   ```bash
   cd backend
   npm install
   npm run start:dev
   ```
   (در صورت نبود Redis روی پورت پیش‌فرض، بک‌اند به صورت خودکار از حافظه موقت در حال اجرا برای تست سریع استفاده می‌کند و در صورت وجود Redis از آن بهره می‌برد.)
